Cloud Computing

Welcome to the Cloud Computing learning website. This website introduces the fundamentals of cloud computing and explains how cloud technologies are changing education, business, healthcare, government and everyday life.

What is Cloud Computing?

Cloud computing is a technology that allows users to access computing resources such as servers, storage, applications and networking services through a network, usually the Internet.

Instead of depending entirely on physical computers and local storage, organisations and individuals can use cloud services provided by cloud computing companies. These services can support flexible access to information, applications and computing resources.

According to the National Institute of Standards and Technology (NIST), cloud computing provides convenient, on-demand network access to a shared pool of configurable computing resources.

Read the NIST definition of Cloud Computing

Why is Cloud Computing Important?

  • Provides access to computing resources through the Internet.
  • Supports remote work and collaboration.
  • Allows organisations to scale computing resources.
  • Supports online storage and backup.
  • Enables organisations to use cloud-based applications.
  • Supports modern digital workplace environments.
