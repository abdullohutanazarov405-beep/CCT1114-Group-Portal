Lifelong Learning

Cloud computing is a continuously developing area of information technology. Lifelong learning is therefore important for anyone who wants to build and maintain cloud computing skills.

What I Learned Independently

While completing this project, I independently explored the fundamental concepts of cloud computing and how cloud services support modern organisations.

I learned about cloud service models such as Infrastructure as a Service (IaaS), Platform as a Service (PaaS) and Software as a Service (SaaS). I also learned about the advantages and challenges associated with cloud computing.

Why Cloud Computing is Important

Cloud computing is important because modern organisations rely on digital services for communication, storage, collaboration, applications and data processing.

Understanding cloud computing can help students develop knowledge that is relevant to modern digital workplaces and future IT roles.

New Knowledge and Skills I Acquired

  • Understanding the basic concept of cloud computing.
  • Understanding IaaS, PaaS and SaaS.
  • Understanding cloud computing applications.
  • Understanding the benefits and challenges of cloud services.
  • Researching technology using credible resources.
  • Organising information into a structured website.
  • Developing HTML pages and connecting webpages.

Skills I Would Like to Develop Further

  1. Cloud infrastructure management
  2. Cloud security
  3. Virtualisation
  4. Cloud networking
  5. Cloud automation
  6. Cloud architecture

My Future Learning Plan

I plan to continue learning cloud computing through online courses, official documentation, practical laboratories and professional certification pathways.

I would also like to gain practical experience by creating small cloud projects and experimenting with cloud services in controlled learning environments.

Lifelong Learning Resources

1. AWS Skill Builder

AWS Skill Builder provides online cloud learning resources, including training that can help learners develop AWS cloud knowledge and practical skills.

Visit AWS Skill Builder

2. Microsoft Learn

Microsoft Learn provides learning paths and modules for Microsoft Azure. It can help learners understand Azure services and develop cloud-related technical skills.

Visit Microsoft Learn Azure Training

3. Google Cloud Learning

Google Cloud provides training resources covering cloud concepts, services and practical learning activities. These resources can support learners who want to develop Google Cloud skills.

Visit Google Cloud Training

4. NIST

The National Institute of Standards and Technology provides authoritative publications about cloud computing. NIST SP 800-145 is particularly useful for understanding the formal definition and characteristics of cloud computing.

Visit NIST Cloud Computing Resources

5. IBM SkillsBuild

IBM SkillsBuild provides online learning opportunities covering technology and digital skills. Learners can use such resources to continue developing their knowledge beyond the classroom.

Visit IBM SkillsBuild

My Reflection

Completing this project helped me understand that learning technology does not only happen inside a classroom. I had to independently search for information, compare concepts and organise what I learned into a website.

The project also helped me realise that cloud computing is a broad field with many areas that I can continue exploring. I would like to improve my practical knowledge and eventually learn more about cloud security, cloud architecture and cloud infrastructure.
