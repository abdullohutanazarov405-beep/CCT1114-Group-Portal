Learn Cloud Computing

Cloud computing provides users with access to computing resources through a network. These resources can include storage, servers, databases, applications and networking capabilities.

Definition

Cloud computing is a model that provides convenient, on-demand network access to a shared pool of configurable computing resources. Resources can be rapidly provided and released with limited management effort.

Cloud computing commonly includes three service models: Infrastructure as a Service (IaaS), Platform as a Service (PaaS) and Software as a Service (SaaS).

Key Features

  • On-demand self-service: Users can obtain computing resources when required.
  • Broad network access: Cloud services can be accessed through network-connected devices.
  • Resource pooling: Computing resources can be shared among multiple users.
  • Rapid elasticity: Resources can be increased or decreased according to demand.
  • Measured service: Cloud usage can be monitored and measured.

Advantages of Cloud Computing

  1. Flexible access to computing resources.
  2. Supports remote working and learning.
  3. Can reduce the need for organisations to maintain physical infrastructure.
  4. Supports collaboration between users.
  5. Allows resources to scale according to requirements.
  6. Provides access to cloud-based applications and storage.

Limitations and Challenges

  • Dependence on a reliable Internet connection.
  • Security and privacy concerns must be managed.
  • Cloud services may experience outages.
  • Organisations may become dependent on a particular provider.
  • Users need appropriate skills to manage cloud technologies.
  • Cloud usage can create ongoing operational costs.

Cloud Service Models

Service Model Meaning Example Use
IaaS Infrastructure as a Service Virtual machines, storage and networking
PaaS Platform as a Service Application development platforms
SaaS Software as a Service Online software applications

Cloud Computing in the Workplace

Cloud computing is used by organisations for many workplace activities. Employees can use cloud-based applications to communicate, collaborate, store information and access business systems.

  • Cloud-based document collaboration
  • Online meetings and communication
  • Cloud storage and file sharing
  • Business applications
  • Data backup
  • Website and application hosting
